# antrahq.com — SEO & UX audit and 30-day plan (12 Oct 2026)

## 1. The headline finding

**Google does not appear to show antrahq.com at all yet** — not for `site:antrahq.com`, and not
for the brand name (a different product, "AntraPro", ranks for "AntraHQ salon software").
Sampled with WebSearch (US-centric, not Search Console data), so confirm in Search Console. The site
itself is technically crawlable (HTTPS, apex canonical, 301s from `www` and `http`, valid
robots.txt and sitemap, Brotli), so the blocker is **discovery and authority**, not code.

Until Google indexes and trusts the domain, no on-page change can put it in the top 3 for
"salon management software India". Fixing that is week 1 of the plan below.

### Realistic 30-day targets

| Query type | Example | Realistic by mid-Nov 2026 |
|---|---|---|
| Brand | `antrahq`, `antrahq salon software` | **#1** — achievable once indexed |
| Long-tail, low competition | `multi branch salon p&l software`, `salon geofence attendance app india`, `antrahq vs fresha` | Page 1, often top 3 |

## 2. What was wrong on the site (and is now fixed in branch `revamp/seo-enterprise-site`)

### Technical SEO
| Issue | Fix |
|---|---|
| FAQPage schema injected on **every** page from the root layout; resource pages then had **two** FAQPage blocks | Site-wide schema is now Organization + WebSite only; FAQ/Software/Article/Product/Breadcrumb schema lives on the page it describes |
| Inner pages reused the homepage `og:title`/`og:url`, so shared links all previewed as the homepage | `pageMetadata()` helper (`src/lib/seo.ts`) sets canonical + OG + Twitter per page |
| Most product, guide, compare and solution titles ran past 60 chars once the brand suffix was added (truncated in Google) | All titles ≤ 60, all descriptions 50–158 chars, all unique (audited in build output) |
| `/products/staff` and `/products/attendance` were duplicate content | Attendance canonicalises to staff and is excluded from the sitemap |
| Sitemap `lastmod` hard-coded to Aug 14 for every URL; privacy/terms missing | `CONTENT_UPDATED` constant drives sitemap + Article `dateModified`; legal pages included |
| No breadcrumbs | Visible breadcrumbs + BreadcrumbList schema on every inner page |
| OG image 1536×1024 declared as 1200×630, old teal brand, "Antrahq" spelling | New 1200×630 on-brand image |
| `llms.txt` listed a stale Gmail address and missed pages | Rewritten with all products, guides, comparisons |
| Hero/section content animated in from `opacity: 0` via framer-motion (invisible until JS runs; hurts LCP) | Homepage is server-rendered with no entrance animations; framer-motion no longer loads on the homepage |
| Generic `keywords` meta (ignored by Google) | Removed |
| No Search Console verification hook | Set `NEXT_PUBLIC_GOOGLE_SITE_VERIFICATION` at build time to emit the meta tag |

### Content
- **New pages:** `/compare/fresha` (the top backlog item; fact-checked against fresha.com/pricing), `/resources/nail-salon-software-india` (nail studios were in the positioning with no landing content), `/products/memberships` (a shipped feature with no page).
- **Product differentiators the site never mentioned** and now does: staff/manager app in 10 Indian languages, memberships & packages with staff credit, verified attendance feeding payroll.
- **Honesty fixes:** `/customers` claimed "named outcomes" while showing illustrative scenarios; trust marquee showed feature names styled as customer logos; "Most chosen" plan badge; "AI agents" section implied agents the product doesn't have. All removed or relabelled.

### UX / visual consistency
- **Three competing brand colours** — fuchsia (runtime theme default), teal (hard-coded Tailwind classes, logo), violet (the product app). Consolidated to one violet token set that matches the app, defined once in `tailwind.config.ts`. The 18-preset runtime theme switcher is removed.
- **Two fonts** (Fraunces serif + Sora) with ad-hoc sizes per section → one family (Plus Jakarta Sans) with a single type scale (`.h-hero`, `.h-section`, `.h-card`, `.lede`, `.body-copy`).
- **Inconsistent containers and padding** (`px-5 md:px-8 lg:px-12` vs header `px-4 sm:px-5…`) → one `.container-wide` and one section rhythm.
- **Homepage length:** 17 sections → 9; 56% shorter on desktop, 53% shorter on mobile. Structure now follows the buyer's questions: what is it → proof → *does it solve my problem* (6 pain → fix tabs, reachable from hero chips) → by role → vs competitors → fit & go-live → price → FAQ → CTA.
- **Accessibility:** header menus were mouse-hover only (now keyboard/click + Escape); demo form labels weren't linked to inputs; FAQ is now native `<details>`; skip link added.
- **CTA vocabulary** unified ("growth audit" / "walkthrough" / "demo" → "Book a free demo").

## 3. The 30-day plan — what only the owner can do (highest impact first)

These need account access, verification or payment, so they are yours. Week 1 matters most.

**Week 1 — get indexed**
1. **Google Search Console**: add `antrahq.com` as a Domain property (DNS TXT record), submit `https://antrahq.com/sitemap.xml`, then use URL Inspection → *Request indexing* on: `/`, `/pricing/`, `/compare/`, `/products/`, `/resources/best-salon-software-india-2026/`, `/compare/fresha/`, `/resources/nail-salon-software-india/` (about 10/day quota).
2. **Bing Webmaster Tools**: import from Search Console (Bing also powers Copilot and other AI search answers). Run `node scripts/submit-indexnow.mjs` after deploy.
3. **Google Business Profile** for AntraHQ (software company, service-area business, India) — wins the brand knowledge panel.
4. **LinkedIn company page + founder posts** linking to the site; add the profile URLs to `sameAs` in `src/app/layout.tsx` once they exist.

**Weeks 2–3 — take the SERP slots competitors already hold**
5. Free listings on **Capterra/GetApp/Software Advice (one Gartner listing), G2, Techjockey, SoftwareSuggest**. These sites hold most page-1 slots for "best salon software India". Ask 5–10 real customers (e.g. the live salon brand already on the platform) for honest reviews.
6. Indian SaaS / startup directories: Product Hunt launch, YourStory company page, Inc42 / Tracxn / Crunchbase profiles — each is a credible link plus a brand result.

**Weeks 3–4 — authority**
7. One genuine guest piece or podcast with a salon-industry publication or association (e.g. a salon-owners community in India) linking to a guide, not the homepage.
8. Publish 1 attributed customer story (named, with permission) — replaces the "illustrative scenarios" and is the strongest conversion asset available.
